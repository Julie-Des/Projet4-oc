# Ohmyfood: Improving a mobile site interface with CSS animations 📱

## 🎯 Project Objectives

The objective of this project was to enhance the **mobile-first interface** of a startup’s website by integrating the provided Figma mockups and implementing **CSS animations** to create an engaging and interactive user experience.

This project is part of the Web Integrator training course – OpenClassrooms.

---

## 🧠 Skills Developed

- **Mobile-First Development** – Building a responsive interface starting from mobile mockups to ensure full adaptability across devices.  
- **UI Integration from Figma** – Translating detailed Figma designs (mobile and desktop) into clean, semantic HTML and CSS.  
- **Sass Mastery** – Writing modular and maintainable styles using variables, mixins, partials, and nesting for better organization.  
- **Code Architecture** – Structuring the stylesheet with a logical hierarchy for scalability and readability.  
- **Version Control** – Using **Git** and **GitHub** for project tracking, commits, and collaboration.  
- **Performance & UX Awareness** – Implementing meaningful animations that improve user experience without compromising performance.  

These skills contribute to developing strong front-end expertise in creating **responsive, animated, and maintainable interfaces** aligned with professional web standards.

---

## ⚙️ Technical Stack

- **Languages:** HTML5, CSS3, Sass (SCSS syntax)  
- **Tools:** Visual Studio Code, Git, GitHub  
- **Design Reference:** Figma  
- **Approach:** Mobile-First Development

---

## 🎞️ Animations Implemented

Several animations were created to make the user interface more dynamic and interactive:

- **Page Loader Animation** – Displayed during page load to indicate initialization.  
- **CTA Button Hover Animation** – Smooth color and scale transition on hover.  
- **Heart Icon Animation** – The heart fills up when hovered to indicate selection or appreciation.  
- **Sequential Menu Load Animation** – Menu sections (starters, mains, desserts) appear one after another when the menu loads.  
- **Dish Hover Checkmark** – A check icon smoothly appears when hovering over a dish.  
- **Text Overflow Animation** – Ellipsis (“…”) appears when dish names exceed the allowed text length for consistent layout.
